# ✨ Lin Scribbles

A handwriting font created from my personal handwriting.

## About
This font is generated from real handwritten samples and designed to preserve
the natural flow, imperfections, and personality of human writing.

## Preview


## Features
- Uppercase & lowercase letters
- Numbers
- Basic punctuation
- Natural handwritten style

## Installation
Download the .ttf / .otf file and install it on your system:
- Windows: Right click → Install
- Mac: Open file → Install Font
