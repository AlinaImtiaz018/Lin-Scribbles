# Code of Conduct

## Our Pledge
We aim to keep this project open, respectful, and welcoming to everyone.

## Expected Behavior
- Respect the creator and contributors
- Provide constructive feedback
- Credit original work when using or modifying the font

## Unacceptable Behavior
- Claiming the font as your own work
- Removing attribution
- Redistributing under misleading names
- Harassment or disrespectful communication

## Enforcement
Any violations may result in removal of access to contributions or project references.

## Attribution
This font is created and maintained by the author of this repository.
